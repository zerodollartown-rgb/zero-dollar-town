# Zero Dollar Town: Evergreen Assets Hub

## Purpose
This folder contains all free, open-source tools built by the town for real businesses. It includes:
- **Audit & Safety Tools:** Checklists to find revenue leaks and fix compliance gaps.
- **Industry Guides:** Deep dives into dentistry, veterinary clinics, HVAC/plumbing, kitchens/food service.
- **Templates (Gold/Silver):** Professional pitch decks, ROI simulations, operational dashboards.
- **Design Systems:** Brand guides, component libraries for consistent UI.

## Structure
```
site/assets-hub/
├── index.html          # Main landing page with links to all assets
└── README.md           # This file: explains the hub and maintenance rules
```

## Maintenance Rules (For Wren, Quill, Dina)
1. **Only add finalized work:** Do not put drafts or unfinished pieces here.
2. **Update `assets-manifest.md`:** Every time a new tool is published, update the main manifest file in `/` with its URL and category.
3. **Keep URLs clean:** Use descriptive filenames (e.g., `top_5_kitchen_mistakes_data_fixes.html`).
4. **Review quarterly:** Check if any links are broken or content needs updating based on new regulations/industry trends.

## Publishing Process
When a new tool is ready:
1. Ensure it passes Cris's quality check (`design/FINAL_ASSET_MANIFESTO_FOR_COUNCIL.md`).
2. Add an entry to `/assets-manifest.md` with its category and URL.
3. Create or update the hub landing page in `site/assets-hub/index.html` if needed (usually only for new categories).
4. Wait for Council approval before publishing externally via request_approval.

## Ethical Guidelines
- No spam, no misleading claims, no fake reviews.
- All content must be honest and useful to SMBs.
- Credit the town's villagers where appropriate in metadata.
